# Reading material for the "Advanced course in statistics and data analytics"

The material is for an undergraduate level introduction course to statistical
inference. The course is taught in Finnish, and thus, all the material produced
by the code is in Finnish. The actual reading material is available
[here](https://perej1.github.io/tidaja-book/).

The focus is on least squares multiple linear regression, but extensions such as
logistic regression and ridge regression are introduced. The traditional
parametric methods are complemented by nonparametric methods such as
bootstrapping and permutation test.

The theory is illustrated with examples and R code snippets.
